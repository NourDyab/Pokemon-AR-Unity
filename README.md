# 🐾 Pokémon AR – Augmented Reality Game

An Augmented Reality Pokémon game developed with **Unity** for Android devices.

The project combines augmented reality, interactive gameplay, Pokémon spawning and movement, Pokéball throwing, and Pokémon catching mechanics.

---

## 🎮 Project Overview

**Pokémon AR** is an interactive AR game where Pokémon can be spawned into the real-world environment through the device's camera.

The player can interact with the Pokémon, throw a Pokéball, and attempt to catch them.

The project was developed as a university project to explore **Augmented Reality, Unity development, interaction systems, and mobile game development**.

## 💻 Main Scripts

### `Pokeball`

Handles the Pokéball object and its interaction within the gameplay.

### `Throw Ball`

Controls the throwing mechanic of the Pokéball and player interaction.

### `Pokemon Catch`

Handles the Pokémon catching logic and determines whether a Pokémon has been successfully caught.

### `Pokemon Movement`

Controls Pokémon movement and behavior within the AR environment.

### `Spawn Pokemon`

Responsible for spawning Pokémon into the augmented reality environment.

### `Generate Monster`

Handles the generation of Pokémon/monster objects used in the game.

### `Monster Lookup`

Provides Pokémon/monster-related lookup functionality.

### `Catch UI`

Controls the user interface and visual feedback related to catching Pokémon.

## 🕹️ Gameplay Flow

The basic gameplay loop is:

```text
Launch the AR application
        ↓
Detect the real-world environment
        ↓
Spawn a Pokémon
        ↓
Pokémon appears in the AR environment
        ↓
Player interacts with the Pokémon
        ↓
Throw the Pokéball
        ↓
Check the catch result
        ↓
Display catch feedback
```

## ⚙️ How to Run the Project

### Requirements

* Unity **6.4**
* Android device with AR support
* Android Build Support installed in Unity
* Required Unity packages listed in `Packages/`

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Pokemon-Go-AR.git
```

2. Open **Unity Hub**.

3. Select **Add Project from Disk**.

4. Select the cloned project folder.

5. Open the project with the appropriate Unity version.

6. Open the main scene from:

```text
Assets/
```

7. Connect an Android device with USB debugging enabled.

8. Build and Run the project for Android.
